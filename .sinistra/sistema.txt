# Lista branca do Sinistra OS

# Tudo listado aqui pertence a Sinistra e e substituido pelo /atualizar-sistema.
# Tudo que NAO esta listado aqui pertence ao cliente e nunca e tocado.
#
# A regra e lista branca, nao lista negra: arquivo ou pasta que o cliente criar
# no futuro ja nasce protegido, sem ninguem precisar lembrar de proteger.
#
# Caminho terminado em / significa a pasta inteira, e a atualizacao apaga a pasta
# local antes de trazer a nova versao. Por isso: so listar pasta que seja 100% da
# Sinistra. Pasta que possa conter arquivo do cliente entra aqui arquivo por
# arquivo, nunca com a barra no fim. E o caso de dados/, marketing/ e saidas/,
# que tem README da Sinistra mas conteudo do cliente.
# Skill oficial e enumerada uma por uma de proposito: e isso que separa skill da
# Sinistra de skill que o cliente criou pelo /mapear-rotinas, ja que as duas
# moram dentro de .claude/skills/.
#
# NUNCA listar aqui: _memoria/, identidade/, marketing/, saidas/, dados/*,
# learnings/*, memory/*, scripts/*, .sinistra/estado.json. Essa e a zona do
# cliente.
#
