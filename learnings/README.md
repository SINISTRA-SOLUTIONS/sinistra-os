# learnings/: o que o sistema aprendeu com o seu negócio

Toda vez que uma tarefa grande é concluída (uma campanha, um plano de SEO, uma
mudança de processo), o sistema escreve aqui o que funcionou, o que não
funcionou e o que evitar da próxima vez.

Um arquivo por assunto, em português comum. Não é log técnico, é memória de
decisão: por que a gente escolheu aquilo e o que aconteceu depois.

Você não precisa escrever nada aqui. O sistema escreve sozinho e lê antes de
sugerir qualquer coisa parecida no futuro. Mas pode abrir e editar quando
quiser, o conteúdo é seu.

Essa pasta é sua. Nenhuma atualização do Sinistra OS encosta no que está aqui.
