# scripts/: as engrenagens

Algumas coisas o sistema não consegue fazer só pensando: gerar uma foto,
transformar um layout em imagem, publicar direto no Instagram. Pra essas, existem
pequenos programas, e é aqui que eles ficam.

A pasta começa vazia. Cada um é instalado quando você usar pela primeira vez a
ferramenta que depende dele.

**Quem instala e configura é a Sinistra.** Isso envolve chaves de acesso do
Instagram, do Facebook e de geração de imagem, e não é coisa pra você mexer. Se
uma ferramenta pedir algo que não está pronto, ela te avisa e você chama a gente.

Essa pasta é sua: o que for configurado aqui fica, e nenhuma atualização do
sistema encosta nela.
